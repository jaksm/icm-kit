A knowledge base about your life that an agent can work in.

It is folders, markdown and git. No vector database, no server, no app to keep running. You can read every file, and so can the agent.

Copy the setup prompt
When do I have to order the greenhouse panels?

    The folder structure is the search engine.

    An agent does not need an index to find one fact among a few hundred files. It needs a map. The file at the top says which area a question belongs to. The file at the top of that area says which record holds the answer. Then it reads the record. Three small reads, and every one of them is a file you can open yourself.

    When it goes wrong, you can see why. If the agent looked in the wrong place, the routing table that sent it there is two lines of markdown, and you fix it by editing them. This is built for one person's few hundred to few thousand records, not for a company's document store. git log says when a fact changed and why.

    Who it is for

    Yes, if all three hold

    • You already use Claude and would rather not explain your situation again in every new conversation. Claude Code is the only agent supported today.
    • You want one place that knows your projects, your numbers, your decisions and the reasons behind them.
    • You can clone, commit and push, and you accept owning an encryption key you must not lose. The agent does the typing; you understand what it is doing.

    No, if

    • You want an app with a login and a sync button.
    • You are not willing to put personal material in one place. An ICM that knows you well personalizes better, at the price of concentrating private data. That trade is the product, so decide it on purpose.

    What it can do

    Stop re-explaining yourself
    Areas for whatever your life has: a business, a house, a body, a trip. Each one routes to its records.
    A morning that starts sorted
    morning-review files the inbox, leaves unread only what needs you, and writes a dated record with proof it ran.
    A feed of your own open things
    feed builds a page for the phone: what is open in your ICM and what arrived from outside, and it reports back what you looked at, so tomorrow's page can follow it.
    Where the money goes
    expenses shows spending per month as aggregates. The parser for your bank is built for you from a recipe, because only yours fits.
    Bring the old system along
    import walks an old notes app or another assistant's memory with you, five items at a time, and keeps what is still alive.

    A graph of every record and link, rebuilt on each commit, so gaps and orphans show.

    What encryption does, and what it does not

    It does

    The repo is pushed through git-remote-gcrypt, so the host only stores an encrypted blob. If the repository or the hosting account is stolen, the thief has nothing to read.

    It does not

    It hides nothing from the AI provider. Whatever the agent reads in a session is sent to the model. What the provider keeps, and for how long, is set by its terms, not by this kit.

    On your own computer the files are plain text. A stolen laptop is a job for the disk encryption of your operating system.

    So read the terms once and choose the setting on purpose. Setup opens it with you before anything personal is written.

    The maintainer's opinion, not a measurement

    Claude, entry paid plan: the best place to start, and excellent for people who are not technical. To my eye it has the smartest models available today, and an ICM lives on judgement more than on volume.

    Codex, entry paid plan: more usage for the same money, and in my experience drastically less clever.

    Antigravity, a mid-priced plan: a lot more usage and a very fast model, and the weakest judgement of the three.

    Ollama and local models: I have not tested them with the kit. They are worth watching, because they solve the privacy question outright.

    Start

    What you need

    A paid Claude plan, because Claude Code is not part of the free one. A GitHub account for the private repo; GitHub only ever sees an encrypted blob, and access from the phone goes through it. git, GnuPG and git-remote-gcrypt, which setup installs with your permission, one at a time. Setup has been run on macOS; the steps for Windows and Linux are written and marked as not yet verified.

    The key is yours alone. If you lose it, the encrypted copy cannot be opened by anyone, which is why setup recommends a recovery USB before anything else personal is written.

    Paste this into Claude Code, in an empty folder or your home folder.

    setup-prompt.md
    I want to set up an ICM: a knowledge base about my own life and work, as markdown files in an
encrypted git repo, that you will work in from now on. Use icm-kit.

First tell me which agent and subscription you are running as. icm-kit works with Claude Code today;
if you are something else, say so and stop, because the adapter for you does not exist yet.

Talk to me in the language I answer in. Before anything else, ask me one question at a time:
what I want this to help with in the next three months, which computer and phone I use, and
whether I have used git, a terminal and encryption keys before. From my answers, decide how much
to explain, and ask me how I like things explained.

Then:
1. Check that git is installed. If it is not, tell me how to install it and wait.
2. Ask where the ICM should live, and clone https://github.com/jaksm/icm-kit there.
3. Open core/skills/setup/SKILL.md in that folder and follow it from step 01. It keeps its state in
   _config/setup.json, so if we stop, I can come back and say "continue setup".

Rules for the whole setup: never ask me for a passphrase or a password in this conversation and
never write one to a file; I type those myself when a window asks. Install nothing and create
nothing outside my computer without asking me first, one thing at a time. When a step is done,
show me the proof, not just the claim.

    What happens next:

    1. It asks what you want help with and how technical you are, then explains at that level, in your language.
    2. It checks what is installed, clones the template, and fills the three personal records in a conversation.
    3. It makes your key and the encrypted remote, recommends a recovery USB, and sets up access from your phone.
    4. It offers the workflows above. Nothing is installed unless you ask.
    5. It ends with an audit of the whole system and shows you the proof. Setup spans several sessions; say "continue setup" to resume.

    The template: icm-kit. What it vendors: icm-kit-core. Components for pages: icm-ui.

    Where this comes from

    ICM is the Interpretable Context Methodology by Jake Van Clief: the folder structure is the orchestration layer, and one agent reading the right files at the right moment does what would otherwise take a framework. The vocabulary here is his: layers 0 to 4, canonical source, contract, checkpoint, _config/.

    His workspace moves one piece of work through numbered stages. An ICM built from this kit holds one person's knowledge in areas that have no order, on the same five layers, and adds what a personal base needs: encryption, access from a phone, and updates that do not touch your data.
